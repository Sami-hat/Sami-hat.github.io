Cryptographically Secure File Server

AES-256 RSA-2048 HMAC-SHA256 JMeter

Overview

An end-to-end encrypted file storage system built in Java with a zero-knowledge architecture. Files are encrypted client-side with AES-256 before upload, ensuring the server never has access to plaintext data.

Security Architecture

AES-256 provides symmetric encryption for file data, RSA-2048 handles key exchange between users, and HMAC-SHA256 ensures integrity verification on every file operation. The system implements granular capability-based access control for fine-grained sharing permissions.

Load tested at 50 concurrent sessions handling 200 operations per second using JMeter. The entire system was validated against OWASP Top 10 vulnerabilities.
