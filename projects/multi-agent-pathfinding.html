Overview

A constraint satisfaction solution for multi-agent pathfinding in automated warehouses. Written as a declarative program in Essence Prime, the model finds optimal collision-free paths for multiple robots simultaneously.

Constraint Model

Decision variables and constraints were carefully designed to ensure collision-free robot paths while optimising total movement costs. Symmetry breaking constraints reduce the search space and improve solver performance.

The model is solved using the Minion constraint solver, demonstrating how declarative constraint programming can tackle real-world logistics optimisation problems.
