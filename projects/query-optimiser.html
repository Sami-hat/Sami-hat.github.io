PostgreSQL Query Analysis and Optimisation

ECS CloudWatch AST parsing

Overview

A PostgreSQL performance analyser that parses query ASTs and evaluates EXPLAIN plans to recommend indexes. Built to identify bottlenecks and missing optimisations in production database workloads.

Analysed 200+ production queries from a five-million-row database, identifying 21 missing indexes across 12 tables, leading to measurable improvements in query execution time.

Technical Highlights

The tool parses SQL queries into abstract syntax trees to understand query structure and access patterns. It then correlates this with PostgreSQL EXPLAIN plan output to identify sequential scans, missing indexes, and suboptimal join strategies.

Deployed on AWS ECS with Docker containers, with CloudWatch integration for monitoring query analysis jobs. D3.js powers an interactive visualisation dashboard that presents index recommendations and performance comparisons.
