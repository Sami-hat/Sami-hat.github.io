Grocery Management App

Redis Node.js Vercel SNS

Overview

A React Native food tracking application designed to reduce household food waste. Users can track groceries, receive expiration alerts, and discover recipes based on ingredients they have on hand.

Technical Stack

The backend is a Node.js REST API deployed on Vercel with an RDS PostgreSQL database. Recipe API integration uses Redis caching to minimise external API calls and improve response times.

Push notifications via AWS SNS alert users when items are approaching expiration. The app was performance tested to verify 60 FPS rendering on mid-tier mobile devices.
