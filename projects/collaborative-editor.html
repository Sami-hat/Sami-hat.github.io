Real-Time Collaborative Code Editor

WebSockets Operational Transform Redis Pub/Sub 50+ Concurrent Editors

Overview

A multi-user code editor built with React and Node.js using WebSockets and Operational Transform for conflict-free concurrent editing. CodeMirror provides syntax highlighting for 12 programming languages.

The Redis pub/sub layer enables horizontal scaling across server instances, achieving sub-100ms synchronisation latency with 50+ concurrent editors. JWT authentication provides per-room permission levels (owner/editor/viewer).

Architecture

The frontend is a React application with CodeMirror integrated for rich code editing. The backend runs on Node.js with Express, using WebSocket connections for real-time communication. Operational Transform algorithms ensure that concurrent edits from multiple users converge to the same document state.

Redis pub/sub handles cross-instance message passing, allowing the system to scale horizontally. PostgreSQL stores session persistence data, enabling users to rejoin documents with full edit history intact. Automatic reconnection handles network loss gracefully.

Testing & Deployment

85+ tests written with Jest and Playwright cover OT convergence edge cases and WebSocket fault tolerance scenarios. The application is deployed on AWS ECS with Docker containers, with GitHub Actions CI/CD for automated testing and deployment.
