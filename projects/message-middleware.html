Message-Oriented Middleware System

Java RMI Pub-Sub FIFO ordering

Overview

A competing-consumer publish-subscribe messaging system built using Java RMI. The system provides asynchronous event distribution across network channels, enabling decoupled communication between distributed components.

Architecture

Partition-based queue management with dynamic load balancing distributes messages evenly across consumers. The system maintains FIFO ordering within partitions to ensure message consistency.

Backup queues provide crash recovery with an at-least-once delivery guarantee, ensuring no messages are lost even during node failures.
