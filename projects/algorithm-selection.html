Automated Algorithm Selection

Scikit-learn SBS/VBS baseline HP tuning

Overview

A solver selection tool that uses Scikit-learn to predict optimal solver performance on a per-instance basis. Given a problem instance and a portfolio of solvers, the system recommends which solver will perform best.

Methodology

Benchmarked multiple machine learning models against Single Best Solver (SBS) and Virtual Best Solver (VBS) baselines using both classification and regression approaches.

Feature normalisation and hyperparameter tuning were applied systematically to improve prediction accuracy. The system demonstrates that automated algorithm selection can significantly outperform static solver choices across diverse problem instances.
